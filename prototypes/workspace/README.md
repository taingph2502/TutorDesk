# TutorDesk Workspace prototype

Throwaway UI prototype for the decision ticket **Prototype the primary Workspace and approval journeys**.

Run from the repository root:

```powershell
node prototypes/workspace/server.mjs
```

Then open <http://127.0.0.1:4173/?variant=A>.

Variants:

- `A` — Examination Bench: stable source viewer, adjacent evidence inspector, Capability dock.
- `B` — Reversible Layers: uninterrupted source stage with contextual learning and Memory Proposal films.
- `C` — Evidence Ledger: source fragments, learning moves, provenance, and approvals aligned row by row.

Use the floating arrows or keyboard Left/Right to switch. All state is in memory and demonstration content is synthetic.

Fonts are locally vendored from Google Fonts:

- Atkinson Hyperlegible, SIL Open Font License 1.1.
- Barlow Condensed, SIL Open Font License 1.1.
